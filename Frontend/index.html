// About PersonaLab

PersonaLab is built for 159.352 Web Development at Massey University. It generates a psychological profile based on the Big Five personality model — analysing Extraversion, Agreeableness, Conscientiousness, Neuroticism, and Openness.

Movie recommendations are pulled from the OMDb API. Pet images are fetched live from public animal APIs. All analysis runs server-side via a FastAPI backend.
